# HackHack 当前版本文件地图

> Git 基线：`main`，提交 `39a78b6`

## 总体调用关系

```text
用户
  ↓
qa.html / qa.js
  ↓ HTTP API
src/server/app.mjs
  ↓
AgentOrchestrator
  ├─ SafetyService
  ├─ SessionService
  ├─ LlmGateway
  ├─ RetrievalService
  ├─ EvidenceService
  └─ AnswerBuilder
       ↓
知乎 Provider + DeepSeek
```

## 1. 前端

### 主展示页

| 文件 | 职能 |
|---|---|
| `src/index.html` | 产品展示页结构 |
| `src/app.js` | 展示内容、导航、动画、图片加载 |
| `src/styles.css` | 展示页样式和响应式布局 |
| `src/assets/images/` | 本地展示图片 |

### 问答测试页

| 文件 | 职能 |
|---|---|
| `src/qa.html` | 问答页结构 |
| `src/qa.js` | 创建 session、发送消息、展示追问/答案、读取来源 |
| `src/qa.css` | 问答页样式 |

问答页流程：

```text
创建 session → 发送消息 → 显示 ask/retrieve/respond
→ 展示 AnswerEnvelope → 请求 /api/sources/{id}
```

## 2. 后端入口与 API

| 文件 | 职能 |
|---|---|
| `src/server/main.mjs` | 启动后端，默认端口 3000 |
| `src/server/index.mjs` | 导出后端模块 |
| `src/server/app.mjs` | 组装所有服务并定义 API |
| `src/server/api/router.mjs` | 路由匹配 |
| `src/server/api/http-server.mjs` | 创建 HTTP Server |
| `src/server/api/request-body.mjs` | 读取/限制请求体 |
| `src/server/api/response.mjs` | 统一响应格式 |
| `src/server/api/routes-health.mjs` | 健康检查 |

核心 API：

```text
POST /api/sessions
POST /api/sessions/{id}/messages
GET  /api/sessions/{id}
GET  /api/sources/{id}
GET  /api/health
```

## 7. 实验目录

### 知乎检索

目录：`experiments/zhihu-retrieval-loop/`

- `cases.json`：测试案例。
- `quota-study-plan.json`：额度感知调用顺序。
- `build-single-queries.mjs`：生成 query。
- `run-search.mjs`：单次搜索。
- `run-experiment.mjs`：Oracle/baseline。
- `run-quota-study.mjs`：配对实验。
- `analyze*.mjs`：统计分析。
- `prepare-quota-annotations.mjs` / `score-quota-annotations.mjs`：评分流程。
- `runs/`：原始调用、标注、评分和汇总。

### DeepSeek 单独测试

目录：`experiments/deepseek-answer-loop/`

```text
冻结知乎 Top-5
→ selector 筛选
→ writer 生成 AnswerEnvelope
→ 校验 schema/source_id/禁用统计
```

- `run-v3.mjs`：推荐 runner。
- `deepseek-json-client.mjs`：保存原始模型内容并解析 JSON。
- `recover-v3-output.mjs`：离线确定性规范化。
- `runs/`：各版本模型原始结果。

### 全链路测试

目录：`experiments/e2e-full-chain/`

- `scenario.json`：场景和验收条件。
- `run-v3.mjs`：推荐后端全链路 runner。
- `README-v3.md`：运行说明。
- `browser-acceptance.md`：浏览器级验收方案。
- `runs/`：成功和失败 trace。
