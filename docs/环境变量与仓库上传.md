# 环境变量与仓库上传

## 文件职责

| 文件 | 是否提交 | 用途 |
|---|---:|---|
| `.env.example` | 是 | 安全模板、默认值和变量清单 |
| `.env.local` | 否 | 本机真实 DeepSeek 与知乎凭证 |
| `config/runtime-state.example.json` | 是 | 运行状态结构示例 |
| `.runtime/state/runtime-state.json` | 否 | 当前机器的实际就绪状态 |
| `.runtime/cache/` | 否 | 可删除缓存 |
| `.runtime/tmp/` | 否 | 临时文件 |
| `.runtime/experiments/` | 否 | 本地实验结果 |
| `logs/` 中的运行日志 | 否 | 可能含 query、摘要或用户输入 |

环境变量描述配置意图，runtime state 描述实际状态。不要把不断变化的 `ready/running/failed` 状态写回 `.env`。

## 新机器或 clone 后初始化

```powershell
node .\scripts\bootstrap-env.mjs
```

该命令只在文件不存在时创建 `.env.local` 和 runtime state，不覆盖已有本地配置。

随后编辑 `.env.local`，填写：

```dotenv
DEEPSEEK_API_KEY=本机私密值
ZHIHU_ACCESS_SECRET=本机私密值
```

不要把真实值写进 `.env.example`。

## 三种推荐状态

### 默认开发状态

```dotenv
DATA_PROVIDER=mock
ALLOW_LIVE_EXTERNAL_CALLS=false
EXPERIMENT_MODE=dry-run
```

效果：不需要密钥，不会误调用外部接口，适合前端和结构开发。

### 小规模接口测试

```dotenv
DATA_PROVIDER=zhihu
ALLOW_LIVE_EXTERNAL_CALLS=true
EXPERIMENT_MODE=smoke
EXPERIMENT_REPETITIONS=1
```

效果：允许 DeepSeek 和知乎真实请求，但只运行小规模测试。

### 完整实验

```dotenv
DATA_PROVIDER=zhihu
ALLOW_LIVE_EXTERNAL_CALLS=true
EXPERIMENT_MODE=full
EXPERIMENT_REPETITIONS=3
```

效果：允许执行完整重复实验。运行前应先检查接口额度。

## 配置检查

```powershell
node .\scripts\env-doctor.mjs
```

脚本不会打印密钥，只输出是否已配置、变量是否有效以及安全开关是否一致，并把结果写入被 Git 忽略的 `.runtime/state/runtime-state.json`。

## 运行知乎实验

使用会自动读取 `.env.local` 的入口：

```powershell
node .\experiments\zhihu-retrieval-loop\run.mjs --strategy baseline --repetitions 1 --count 10
```

不要再直接运行 `run-search.mjs`，除非已经通过进程环境变量或 Node 的 `--env-file` 参数注入配置。

## 历史凭证文件迁移

如果仓库根目录存在旧的 `zhihuaccess.env`：

```powershell
node .\scripts\migrate-legacy-secret.mjs
```

脚本不会显示密钥。它会把值写入被忽略的 `.env.local`，并把旧文件移动到被忽略的 `.runtime/secrets/`，避免误提交。

## 上传仓库前检查

```powershell
git status --short
git check-ignore -v .env.local .runtime\state\runtime-state.json
git diff --cached --name-only
```

预期：

- `.env.local` 和 `.runtime` 状态文件显示为 ignored；
- staged 文件中只有 `.env.example` 和状态示例，没有真实 `.env.local`；
- 不应出现 `zhihuaccess.env`、实验运行 JSONL 或真实日志。

如密钥曾经进入 Git 提交，仅添加 `.gitignore` 不够；应立即轮换密钥，并单独清理 Git 历史。
